# Challenge 2 — IRA y neumonía en menores de 5 años en el Perú

Repositorio académico que reúne el informe Markdown, la página web interactiva y las gráficas del caso.

## Ver la página
Con GitHub Pages habilitado para la rama `main` y la carpeta `/ (root)`, la URL del proyecto es:

https://kevinesty.github.io/Challenge_2_kevin_carvallo/

## Contenido
- `index.html`: página principal.
- `styles.css`: diseño adaptable a móviles y escritorio.
- `script.js`: gráfico interactivo de las series anuales.
- `challenge_ira_neumonia_peru.md`: informe del caso.
- `grafico_episodios_ira.png`: episodios de IRA 2023–2025.
- `grafico_defunciones_neumonia.png`: defunciones por neumonía 2023–2025.
- `grafico_de_defunciones.png`: comparación de defunciones.
- `grafico_regresion_ira.png`: tendencia lineal ilustrativa.

## Publicar en GitHub Pages
1. Abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona `main` y `/(root)`.
4. Guarda los cambios y espera a que termine el despliegue.

## Nota sobre los datos
Las cifras proceden del material de referencia compartido para el trabajo y no se han verificado independientemente en este paquete. La matriz de puntuación es ilustrativa, no oficial.
